# 本地中文后台使用说明

## 打开后台

当前地址：`http://127.0.0.1:8780/admin/`。只在这台电脑可用，不是线上管理入口。

以后双击源码目录中的 `start-admin.cmd`。需要 Node.js 24；第一次启动会安装锁定的项目依赖。保持启动窗口运行，关闭它会停止后台，但已经保存的草稿不会丢失。端口被占用时不要重复启动同一后台。

## 修改中文

1. 左侧找页面；“全站公共文字”管理导航、页眉和页脚。
2. 搜索本页文字，点击“编辑”，修改中文并“保存中文草稿”。原始中文和当前英文可展开核对。
3. 点击中文预览检查效果。图片使用文件选择器导入 PNG/JPEG/WebP，单张不超过 10 MB；原图片不会覆盖。
4. 修改错误可在“修改记录”恢复。关闭编辑窗口前未保存的输入不会自动保存。
5. 全部改完告诉 Codex：“我改好了，请同步英文并制作上传包。”

保存不会改变线上网站。中文改动会标记英文待同步；有待同步内容时不能制作正式上传包。链接和图片路径无需翻译，会同时绑定双语页面，但仍会检查目标是否存在。更改公司身份、电话或邮箱前，请检查公共字段和所有出现位置。

后台编辑的是现有内容字段，不提供任意 HTML、页面重排、新增页面或在线部署。带内链的段落分成正文片段和链接文字/地址，修改时保留它们的关系。SEO 标题、描述和社交预览字段单独显示；Codex 同步时会一起核对。

## 英文同步与上传

Codex 执行 `npm run sync` 可导出 `.local-admin/english-pending.json`；翻译和事实核对完成后，使用 `npm run sync -- <已核对的翻译JSON路径>` 导入。每条英文绑定中文修订号，中文再次修改后必须重新同步。

`npm run package` 或界面的“生成上传包”只制作本地文件，绝不发布。输出位于本站 `reports/local-admin-2026-10-17/releases/<时间>/`，含完整源码 ZIP、静态成品 ZIP 和 SHA256 清单。静态 ZIP 本身不提供询价邮件 API。正式发布仍需你当次授权，由 Codex 走 GitHub → Vercel。

## 数据与备份

- 维护源码：`E:/Ellis-Services/Canberra Woodwork/source`。
- 草稿和历史：`.local-admin/state.json`，保存在磁盘，不是浏览器缓存。
- 确认双语内容：`content/approved.json`，只有检查通过的本地打包才会更新。
- 新图片：`public/assets/uploads/`。
- 请备份源码、`.local-admin/state.json` 和新图片；发布 ZIP 故意不包含草稿历史和任何密钥。

冲突提示表示另一个窗口已有新保存：先保留当前输入，再刷新并比较，不要覆盖。若电脑断电后留下 `write.lock`，请先关闭后台并让 Codex核对没有写入进程后再处理；不要自行删除正在使用的锁。

## 开发验证

运行 `npm run typecheck`、`npm test`、`npm run build`。生产维护代码在 `build.mts`、`src/*.mts`、`browser/*.ts`、`api/contact.ts`；少量 `.mjs` 是构建入口/工具和生成兼容产物，HTML、CSS、JSON、图片仍保留其合适格式。

英文同步由当前 Codex 会话按你的通知执行，不是后台自动翻译，也不会在会话结束后自动监控。翻译只处理你批准公开的内容，不传密钥或客户私密资料给外部模型。
